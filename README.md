## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_movie_contact`** provides a dedicated contact and screening inquiry desk for **UNIVERSE HUOKAING THARA Group**. Visitors can filter inquiry desks, search topics live, pre-fill the contact form from any desk card, and generate a reference receipt (`UHT-FILM-XXXXXX`) upon submission.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Desk Filtering:** Filter inquiry desks (*Screenings, Production, Media & Partners*) or search keywords and topics in real time.
* **⚡ One-Click Topic Pre-Fill:** Select a desk topic to automatically set the inquiry dropdown and smooth-scroll to the contact form.
* **🧾 Confirmation Receipt & Reference Copy:** Generates a reference code upon form submission with one-click clipboard copy support.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
